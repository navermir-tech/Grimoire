# 하우징 · 거점

> 관련 요구사항: R11(집 짓기 · 꾸미기 · 농사 · 생산), R02(생물 자동화), R16(마법 상호작용)
>
> 레퍼런스: 팰월드(거점 + 일꾼), 인슈라오디드(자유 건축 · 꾸미기), 아크 서바이벌(생존 거점)

## 거점이란

- 플레이어(또는 파티)가 **거점 핵**(마법진)을 놓은 곳 주변 반경이 거점이다. 거점 안에서 건축 · 농사 · 생산 · 생물 배치가 된다.
- 거점은 **생존의 기준점**이다: 잠, 요리, 저장, 부활 지점, 완드 제작.
- 거점 수(Q10 확정): 플레이어당 1 → 서클이 오르면 늘어남(최대 3).

## 집 짓기

- **조각 건축 — 팰월드 크기의 큰 블록**(R30): 바닥 · 벽 · 지붕 · 문 · 계단 · 기둥 조각을 **격자에 스냅**해 짓는다. 인슈라오디드처럼 작은 블록을 한 칸씩 쌓는 방식은 쓰지 않는다. 재료: 나무 · 돌 · 마법 결정.
- 조각 크기(제안, Q33): **바닥 4m × 4m, 벽 높이 3m**. 문은 사람용 한 칸 · 큰 생물용 두 칸 폭. 반 칸(2m) 조각(반 벽 · 난간 · 창)만 따로 두어 모양을 다듬는다.

**검토 — 왜 큰 블록인가**

| | 큰 블록(팰월드 · 아크) | 작은 블록(인슈라오디드 복셀) |
|---|---|---|
| 짓는 속도 | 집 한 채가 몇 분 — 생존 · 생물 · 탐험 사이의 「일」로 맞다 | 한 칸씩 쌓아 오래 걸린다 — 건축 자체가 놀이인 사람에게 좋다 |
| 큰 생물 | 4m 칸 · 두 칸 문으로 대형 탈것 · 일꾼이 드나든다(R02) | 통로를 따로 크게 파야 한다 |
| 지붕 · 실내 판정 | 조각 단위라 단순 — 비 · 체온 「지붕 아래」(R25 · R29)가 정확하다 | 블록이 잘아 판정이 비싸고 틈이 생기기 쉽다 |
| 내구도 · 습격 · 불 번짐 | 조각 수가 적어 내구도 · 수리 · 불 번짐(R16)을 조각마다 셀 수 있다 | 블록 수가 너무 많아 조각마다 상태를 들기 어렵다 |
| 멀티 · 세이브 | 조각 수가 적어 복제 · 저장이 가볍다 | 블록 수만큼 무겁다 |
| 꾸밈의 자유 | 모양은 덜 자유롭다 → **가구 · 장식은 격자 없이 자유 배치**로 보완 | 아주 자유롭다 |

→ 그리모리는 건축이 생존과 생물의 받침이라 **큰 블록 + 자유 배치 가구**가 맞다. 꾸미기의 재미는 가구 · 조명 · 장식과 쾌적도 보너스(아래)로 낸다.
- 지붕이 있으면 비를 막는다 → 안의 불이 안 꺼지고 체온이 유지된다. 집이 곧 생존 수단이다.
- 마법 건축(제안): 땅 마법으로 기초 다지기 · 흙벽, 불 마법으로 벽돌 굽기. 기본 조작은 건축 UI 지만 마법으로 더 빠르다.

## 내구도 · 수리 (R18)

- 건축 조각 · 시설은 **내구도**가 있다. 0 이 되면 **부서지고** 재료 일부를 잔해로 떨군다.
- 닳는 까닭:
  - **습격** — 사냥꾼 · 사나운 생물의 공격.
  - **속성 상태(R16)** — 나무 조각은 불이 붙으면 타면서 내구도가 준다(불은 옆 조각으로 번진다). 돌 · 벽돌은 타지 않는다. 얼음 조각은 더위에 녹는다. 그래서 재료 선택이 곧 방어다.
  - **노후** — 시간이 지나면 닳는다. **거점 안은 아주 느리게**, **거점 밖은 아주 빠르게** 닳는다(R30 — 밖에 지은 쉼터는 잠깐 쓰고 버리는 것). 수치는 설정(제안: 안 = 실제 며칠에 걸쳐 조금, 밖 = 하루 안에 크게).
- **수리는 재료가 든다**. 조각의 재료(나무 · 돌 · 결정)를 들고 **노말(무속성) 수리 마법 「수리」**를 건다 — 장비 수리와 같은 마법(R30 확정). 재료 1개 = 최대 내구도 25%.
- 「수리」를 배우기 전에는 **마법탑 NPC 에게 재료 + 수수료로 의뢰**할 수 있다 — 의뢰하면 거점의 닳은 조각을 **한 번에** 고친다.
- 한 번에 고치기: 거점 핵에서 「거점 수리」 — 저장고의 재료로 닳은 조각을 모두 고친다(마나 많이 듦 — 확정).
- 서버 옵션: 건축 피해 배율 · 노후 끄기 · 최대 내구도 배율(팰월드에도 같은 설정이 있다).

## 꾸미기

- 가구 · 조명 · 장식 조각. 조명은 **양초 · 횃불 · 마법등**이고 켜려면 불 · 빛 마법을 쓴다(R16).
- 꾸미기에 기능 보너스(확정): 쾌적도가 높으면 잠으로 회복하는 피로 ↑, 일꾼 생물의 사기 ↑. 쾌적도는 방(지붕 · 벽으로 닫힌 공간) 안의 가구 · 조명 · 장식 점수 합(제안).
- 가구 · 장식은 격자에 묶이지 않고 **자유 배치**(바닥 · 벽 위 어디든, 회전 자유) — 큰 블록 건축의 꾸밈을 보완한다.

## 농사

- 밭(땅 마법으로 고른다) → 씨앗 → 생장 단계 → 수확.
- 생장 조건: **물**(비 또는 물 마법 또는 물 생물 급수) · **빛**(낮 또는 빛 마법) · **온도**(기후 — 설산에선 온실 필요). 불 마법으로 밭을 태우면 재가 비료.
- 작물은 식량 · 약초 · 마법 재료(마나초, 잉크꽃)로 나뉜다.

## 생산

| 시설 | 만드는 것 | 마법 연동 |
|---|---|---|
| 작업대 | 건축 재료, 도구, 방어구 | 「수리」 마법을 걸 자리 |
| 가마 · 화로 | 벽돌, 유리, 금속 | 불 마법으로 가열, 바람으로 온도 ↑ |
| 요리대 | 요리, 보존식 | 불 마법 |
| 완드 공방 | 완드 제작 · 개조 · 수리 | 속성 재료 + 해당 속성 마법으로 각인 |
| 각인대 | 장비 인챈트 · 지우기 | 인챈트 속성의 마법 + 소재 ([장비](./equipment#인챈트-—-강화-r19)) |
| 번식장 | 생물 번식 | — |
| 저장고 | 보관 | 어둠 마법으로 부패 지연(제안) |

- 생산은 **대기열**이다. 재료를 넣으면 시간이 걸리고, 적성 있는 일꾼 생물이 있으면 빨라진다.

## 멀티에서의 거점

- 파티 공용 거점. 권한(건축 · 철거 · 저장고 열기)은 거점 주인이 준다.
- 사냥꾼의 **습격 이벤트**가 거점을 노린다(Q10 확정) → 방어 시설(돌벽 · 마법 결계)의 쓸모.
