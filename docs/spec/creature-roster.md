# 지역별 생물 명단

> 관련 요구사항: R14(생태계), R35(도감 확장 룰), R37(생물 출처). 상태: **제안**(2026-11-06) — 이름 · 수치 · 서클은 종 데이터로 두어 바꾸기 쉽다.

10 × 10 km 세계의 8지역([세계 — 지역과 크기](./world#지역과-크기-r34-—-q36-확정))에 어떤 마법 생물을 두는지 정한 명단이다. 생물 하나하나의 규칙(속성 1~2 · 고유 능력 · 길들이기 · 개체 차이)은 [마법 생물](./creatures)을 따른다. 명단의 정본은 `art/creatures/make_prompts.py` 의 `CREATURES` 이고, 아래 표는 `python -X utf8 art/creatures/make_prompts.py --md` 로 뽑았다 — 명단을 고치면 그 파일을 고치고 표를 다시 뽑는다.

## 고르는 기준

- **바탕은 나무위키 「상상의 동물/목록」**(R37). 목록에서 동물 · 짐승 꼴인 것을 먼저 고르고, 지역의 기후 · 주 속성에 맞는 전승을 붙였다(설산 = 북유럽 · 히말라야 · 일본 설녀, 화산 황야 = 서아시아 · 이집트 · 연금술, 깊은 숲 = 핀란드 · 슬라브 · 웨일스).
- **전설(☆ — 한 마리뿐인 개체)은 지역마다 하나**만 둔다. 잡을 수 없고, 시험을 통과하면 축복을 주는 상대다. 그 밖의 전설은 **아래 혈통 · 작은 친척을 창작**해 흔하게 만난다(아래 「창작 생물」).
- 지역마다 층을 고루 채운다: **주변 · 작은 생물 → 사냥감 · 가축 → 포식자 → 탈것 · 일꾼 → 필드 보스 → 전설**. 낮 · 밤 · 조건부(비 · 뇌우 · 안개 · 눈 · 모래폭풍)를 섞어 시간마다 다른 생물이 보이게 한다.
- **먹이 사슬**: 지역마다 초식 · 피식자(사냥감 · 가축)와 그것을 쫓는 포식자를 짝지어 둔다(예: 1번 재칼로프 · 흙닭 ← 불씨여우 · 검은 개).
- **일하는 생물은 일부만**(아래 「기능」). 새 지역에 가면 새 기능 변형이 하나 이상 생긴다.
- 1번 지역(오픈 베타 전부)은 약하고 길들이기 쉬운 종 위주(1~3서클) — [종 수 배분](./creatures#종-수-배분-q15)의 「탑 지역은 쉬운 종」과 같다.

|---|---|---|
| 맨드레이크(사람 모양 뿌리) | 맨드레이크 뿌리두더지 — 순무 몸통 · 두더지 앞발 · 잎 볏 | 뽑으면 우는 비명 |

| 세이렌(사람 머리 새) | 세이렌 바다새 — 소리주머니가 빛나는 바다새 | 홀리는 노래 |

## 기능 — 모든 생물이 일하지 않는다

길들인 생물이 플레이어 · 거점에 해 주는 일을 **기능**이라 한다. 팰월드처럼 모든 생물이 생산 행동을 하지 않는다 — **기능 없음(야생 · 길들여도 동행 · 전투만)이 기본**이고, 기능은 일부 생물만 가진다. 한 생물이 기능 둘을 가지는 일은 드물게만(지금 3종). 기능이 없는 생물도 사냥 재료 · 생태 상호작용 · 전투 동료로 값어치가 있다(도감 확장 룰 4 · 5).

| 기능 | 게임에서 하는 일 |
|---|---|
| **날것** | 하늘을 나는 탈것 — 비행 · 활공. 지형을 건너뛴다(높은 서클) |
| **탈것** | 땅 · 물 탈것 — 달리기 · 헤엄 · 오르기. 탄 채 시전(Q9) |
| **목축** | 거점에 두면 산물을 주기적으로 낸다 — 털 · 알 · 젖 · 점액 · 먹물. 죽이지 않고 얻는 재료 |
| **손재주** | 거점 작업 보드의 손일 — 채집 · 벌목 · 채광 · 농사(밭갈이) · 제작 보조(실 잣기) |
| **운반** | 짐을 나른다 — 거점 안 상자 사이 옮기기, 데리고 다니면 짐칸(무게 한도 ↑) |
| **방범** | 거점 · 주인을 지킨다 — 경비 · 침입 경보 · 정찰 |
| **속성 작업** | 속성으로 하는 거점 일 — 급수(물) · 불 지피기(불) · 냉장(얼음) · 치유(신성) |

- **거점 최소 기능** = 손재주 · 목축 · 속성 작업 · 방범. 1번 지역만으로 넷이 다 갖춰진다(오픈 베타에서 거점이 돈다). 2번 지역부터는 지역마다 일부러 빈 기능이 있다 — 앞 지역에서 길들인 생물을 데려와 채운다. 지역마다 **새 기능 변형**(벌목 · 실 잣기 · 채광 · 냉장 · 치유 · 강 운반)을 하나 이상 얻게 했다.
- 기능의 세부(작업 속도 · 산물 주기 · 일꾼 피로)는 M5 일꾼 · 작업 보드 설계에서 정한다.

| 콘셉트 `<id>` | `prompts/<id>.txt` → `raw/<id>.png` | 3/4 앞 시점 전신, 연한 단색 배경, 1.8 m 사람 실루엣(축척), 아래 띠에 색 변이 3개(기본 · 암수 · 돌연변이). 1536 × 1024 |
| 4면 시트 `<id>-sheet` | `prompts/<id>-sheet.txt` → `raw/<id>-sheet.png` | 콘셉트 그림을 참고로 같은 개체의 2 × 2 시트(왼쪽 위 정면 · 오른쪽 위 왼쪽 · 왼쪽 아래 뒤 · 오른쪽 아래 오른쪽). Tripo 멀티뷰 입력용 — [그림 작업 폴더](https://github.com/navermir-tech/Grimoire/blob/main/art/README.md) 「환경 에셋 만들기」와 같은 길 |

공통 스타일 문단(톤 · 금지 목록)은 `make_prompts.py` 의 `STYLE` 하나에 있다 — 고치면 모든 프롬프트가 함께 바뀐다.

**1단계 — 콘셉트 61장**(Git Bash, 저장소 뿌리에서):

```bash
bash art/tools/run_batch.sh /c/dev/Grimoire/art/creatures 3 $(python -X utf8 art/creatures/make_prompts.py --list)
```

**2단계 — 4면 시트**(콘셉트를 눈으로 고른 뒤. `--list-sheets` 는 `raw/<id>.png` 가 있는 생물만 내놓는다):

```bash
bash art/tools/run_batch.sh /c/dev/Grimoire/art/creatures 3 $(python -X utf8 art/creatures/make_prompts.py --list-sheets)
```

- `--list` 는 프롬프트를 먼저 다시 쓰고 작업 이름만 출력한다. 이미 `raw/<id>.png` 가 있는 작업은 `run_batch.sh` 가 건너뛰니, 마음에 안 드는 그림은 지우고 다시 돌린다.
- 동시에 돌리면 결과가 섞일 수 있다(`art/README.md` 「함정」) — 다 뽑은 뒤 눈으로 보고 틀린 것만 혼자 다시 돌린다. 몇 종만 뽑을 때는 `--list` 대신 작업 이름을 직접 적는다(`... 3 kelpie otso`).
- `prompts/*.refs`(시트의 참고 그림 경로)는 돌리는 컴퓨터의 절대 경로라 커밋하지 않는다.
