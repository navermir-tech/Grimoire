# 아트 방향

2026-11-06 사용자 결정. 레퍼런스는 **케나: 브릿지 오브 스피릿츠** · **호그와트 레거시**. 방향만 빌리고, 두 게임의 에셋 · 캐릭터 · 건물 모양은 따라 만들지 않는다.

## Painterly High-Fidelity Stylized Realism

> 회화적인 색채와 판타지적 미술 방향성을 기반으로 하되, 고품질 3D 모델링과 사실적인 PBR 재질, 정교한 환경 디테일을 결합한 스타일.

| 키워드 | 우리 게임에서 뜻하는 것 |
|---|---|
| High-Fidelity 3D Modeling | 실루엣이 단순한 블록이 아니다. 돌 모서리 깎임 · 나무 결 · 이음매까지 모델에 있다(Nanite 정적 메시) |
| Stylized Realism | 형태는 조금 과장한다(두꺼운 기둥 · 기울어진 지붕 · 큰 나뭇잎 덩어리). 재질은 사실적으로 둔다 |
| Painterly Color Grading | 화면 전체 색은 그림처럼 — 따뜻한 밝은 곳 · 푸른 그림자 · 채도 높은 초록과 금빛. 후처리(색 보정)와 재질 색 조절로 맞춘다 |
| Realistic PBR Materials | 거칠기 · 노멀 · AO 가 제대로 있는 재질. 손그림 텍스처(빛을 그려 넣은 것)는 쓰지 않는다 |
| Cinematic Lighting | Lumen 전역 조명 · 낮게 깔리는 해 · 빛줄기(볼류메트릭) · 실내 창빛 |
| Detailed Environment Art | 바닥에 돌 · 낙엽 · 이끼 · 풀이 겹겹이. 빈 땅이 넓게 보이지 않는다 |
| Atmospheric Perspective | 멀수록 푸르고 옅게(높이 안개 · 대기). 랜드마크 실루엣이 안개 위로 보인다 |
| Fantasy Aesthetic | 마법 빛(마나 빛줄기 · 룬) · 떠 있는 돌 · 비현실적인 크기의 나무 |

## 두 레퍼런스에서 가져올 것

- **케나**: 숲의 색 — 채도 높은 초록 · 주황 단풍 · 부드러운 빛 번짐. 둥글고 큰 형태의 식생, 따뜻한 역광.
- **호그와트 레거시**: 고딕 · 중세 건물의 재질 밀도(돌 · 나무 · 철), 실내 조명 연출, 넓은 풍경의 대기 원근과 랜드마크 실루엣.

## 리소스 만드는 길 — 자체 제작(GPT · Tripo · 블렌더)

2026-11-06 사용자 결정: 사 오지 않고 **최대한 직접 만든다**. 도구마다 잘하는 것만 맡긴다.

| 도구 | 맡는 것 | 맡기지 않는 것 |
|---|---|---|
| **GPT**(codex) | 콘셉트 아트 · 색 기준표 · **Tripo 입력 그림**(물체 하나 · 무늬 없는 배경 · 고른 빛 · 정면/옆/뒤) · 잎 · 꽃 · 룬 같은 알파 텍스처 · 데칼 | PBR 재질 원본(거칠기 · 노멀이 없다) |
| **Tripo**(그림 → 3D) | 바위 · 석상 · 제단 · 그루터기 · 소품 · 장식 조각 · 생물 — 둥글고 덩어리진 것 | 반듯한 건물 벽(모서리가 무르다) · 얇은 잎과 풀(구멍 · 뭉개짐) |
| **블렌더**(내가 스크립트로 돌리고, 사용자가 다듬는다) | ① 정리: 실제 크기(cm) · 바닥 기준점 · 메시 정리 · 텍스처 다시 굽기 · 충돌 · 언리얼로 내보내기 ② 건물 모듈 키트(4m 격자 벽 · 기둥 · 아치 · 지붕, 모서리 깎임 · 돌 이음매까지) ③ 반복 재질: 절차적 노드로 돌 · 흙 · 나무 결을 만들어 PBR 맵(색 · 노멀 · 거칠기 · AO · 높이)으로 굽기 ④ 나무 · 풀: 지오메트리 노드 줄기 + GPT 잎 텍스처 카드 | — |
| **언리얼** | 마스터 재질 `M_GrimEnv_Master`(색조 · 채도 · AO 색 · 큰 무늬 손잡이)로 모든 에셋 색을 한데 묶기 · Nanite · PCG 로 뿌리기 · 화면 톤(Lumen · 안개 · 색 보정) | — |

### 한 에셋이 지나는 길

1. GPT 콘셉트 → 사용자 확인
2. GPT 가 같은 물체의 Tripo 입력 그림(정면 · 옆 · 뒤)을 뽑는다
3. Tripo 로 3D(GLB, PBR 텍스처)
4. 블렌더 정리 스크립트 → `art/<에셋>/` 에 `.blend` · 언리얼용 파일
5. 언리얼 가져오기 스크립트: `Content/Grimoire/Environment/<종류>/` 에 넣고 마스터 재질 인스턴스를 씌운다
6. 그레이박스 블록 자리에 바꿔 놓고 눈높이 스크린샷으로 확인

건물처럼 반듯한 것은 2~3 대신 블렌더 모듈 키트로 만들고, 장식(문장 · 석상 · 덩굴)만 Tripo 로 붙인다.

## 확인 기준

- 눈높이(1.8m) 스크린샷을 레퍼런스 옆에 두고 본다 — 색 온도 · 안개 깊이 · 바닥 밀도.
- 텍셀 밀도를 한 값으로 맞춘다(가까이 보는 것 기준). 값은 마스터 재질을 만들 때 정해 [기술 설계](../systems/terrain)에 적는다.
- 출처가 다른 에셋을 나란히 놓고 색이 따로 놀지 않는지 본다.
