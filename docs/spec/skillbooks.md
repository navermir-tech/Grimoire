## 이름 짓는 법 (R31)

[주문 이름 규칙](./magic#주문-이름-r31) 세 가지를 그대로 따른다.

1. **기본 주문은 고유한 이름** — 라틴어 낱말을 바탕으로 한 두세 음절(플라미스 ← flamma, 벨룸 ← velum 「장막」).
2. **파생 주문은 기본 주문 이름 + 꼬리말** — 원리는 같고 크기 · 수 · 지속 · 모양만 다르다(이그니스 → 이그니스 멀티플렉스 · 이그니스 막시마).
3. **원리가 다르면 새 이름** — 같은 불이라도 플라미스(불꽃 생성) · 이그니스(화염 구체) · 칼로르(몸 데우기) · 포르낙스(화염 회오리)는 다른 주문이다.

| 꼬리말 | 뜻 | 쓰인 곳 |
|---|---|---|
| **막시마** | 더 크게 · 강하게 | 스쿠툼 · 모베오 · 쿠스토디아 · 레스티투오 · 파크툼 · 이그니스 · 아쿠엘 · 벤투스 · 비멘 · 푸르가 · 풀멘 막시마 |
| **멀티플렉스** | 여러 발 · 여러 갈래 | 이그니스 · 스티리아 · 풀멘 · 마쿨라 멀티플렉스 |
| **퍼페투아** | 오래 지속 | 겔루 퍼페투아(얼음길) · 살투스 퍼페투아(활공) |
| **로타** | 돌며 · 원형으로 | 플라미스 로타(불꽃 고리) · 사나 로타(치유의 원) |
| **실렌타** | 조용히 · 은밀히 | (아직 없음 — 그림자술 파생에 남겨 둠) |

- **표기**: 스킬북 · 그리모어엔 한글 주문 이름(**플라미스**)과 한국어 별칭(불꽃 생성)을 함께 쓰고, 책 표지 · 시전 대사 자막엔 라틴 대문자(`FLAMMIS`)를 쓴다. 아이템 이름은 지금처럼 「스킬북: 플라미스」.
- **속성 이름**(파크툼 뒤에 붙는 말): 이그니스(불) · 아쿠아(물) · 글라키에스(얼음) · 벤투스(바람) · 테라(땅) · 플로라(풀) · 상투스(신성) · 룩스(빛) · 말레디카(흑마법) · 움브라(그림자술). 「이그니스」 · 「벤투스」는 주문 이름이자 속성 이름이다 — 이미 정해진 대로(Q34) 둔다.
- 다른 작품의 주문과 겹치지 않게 골랐다(라틴어 낱말 그대로는 쓰되, 이미 널리 알려진 주문 이름 — 예: 방패 · 빛 · 수리 · 치유 주문 — 은 피했다).

## 칸 읽는 법

**방식** — 마법이 대상에 닿는 길. 앞의 다섯은 이미 정의에 있고([투사체 · 시전 감각](../systems/spell-feel#전달-방식-delivery-다시-정의)), 뒤의 다섯은 이 목록이 새로 쓰는 방식이다(Q44 확정 — 나중에 더하거나 바뀔 수 있다).

| 방식 | `Delivery` | 무엇 | 예 |
|---|---|---|---|
| 섬광형 | `Bolt` | 빠른 투사체, 락온 대상 쪽으로 살짝 휜다 | 플라미스 · 스티리아 · 파크툼 |
| 줄기형 | `Stream` | 누르는 동안 포물선 줄기, 초당 마나 | 아쿠엘 |
| 원뿔형 | `Cone` | 앞쪽 원뿔 안 모두, 거리별 세기 | 벤투스 · 겔루 · 운다 |
| 광선 | `Beam` | 곧은 즉시 판정. 누르는 동안 이어지는 것도 | 풀멘 · 모베오 · 하우리오 |
| 포물선 | `Lob` | 중력 받는 덩어리, 떨어진 곳에서 터진다 | 라피스 |
| 자신 | `Self` | 시전자에게 건다(버프 · 이동 · 은신) | 칼로르 · 살투스 · 칼리고 |
| 아군 | `Ally` | 락온이 아군을 잡는다. 대상이 없으면 나 | 사나 · 푸르가 |
| 지점 | `Ground` | 겨눈 땅에 놓는다(벽 · 장판 · 샘 · 회오리) | 무루스 · 벨룸 · 포르낙스 |
| 몸 둘레 | `Aura` | 내 둘레에 몇 초 지속 | 플라미스 로타 · 트레모르 |
| 지역 | `Region` | 날씨 · 지역 상태를 바꾼다(9 · 10서클) | 솔라리스 · 딜루비움 |

**마나 · 쿨** — 수치는 마법 정의(`DA_Spell_*`)와 밸런스 표에서 정하고, 여기엔 급만 적는다. 숙련도가 오르면 둘 다 준다(D 100% → S 75 · 80%).

| 마나 | 기준(1회) | 쿨 | 기준 |
|---|---|---|---|
| 없음 | 0 | 없음 | 0 |
| 하 | ~10 | 짧음 | ~1초 |
| 중 | 11~30 | 보통 | 1~5초 |
| 상 | 31~60 | 김 | 5~30초 |
| 최상 | 61~ | 아주 김 | 30초~ |
| | | 하루 | 게임 하루(48분)에 한 번 — 지역 마법 |

**상태** — ✅ 있음(코드 · 에셋), M7(수직 슬라이스에 넣는다), M4 · M5(그 시스템과 함께), 뒤(슬라이스 뒤).

### 책의 모습 (제안)

- 표지 = **속성 색**(그리모어 문양과 같은 색 · 같은 문양), 등 장식 = **서클 띠**: 1~3 가죽 끈 · 4~6 은장 · 7~9 금장 · 10 스스로 빛남. 바닥에 떨어진 책만 봐도 무슨 속성 · 몇 서클인지 안다.
- 노말은 무속성 문양(옅은 하늘빛), 파크툼은 금빛 계약 인장.

## M7 슬라이스 24

로드맵 M7 의 「마법 24(속성당 4)」를 **R07 의 여섯 계열 × 4**로 읽었다(Q39 확정 — 나중에 바뀔 수 있다). 갈래가 둘인 계열(물 · 땅 · 빛 · 어둠)은 두 갈래를 섞어 넷을 채운다. 24 에는 노말(기본 공격 · 스쿠툼 …)과 파크툼은 세지 않는다.

| 계열 | 1서클 | 2서클 | 3서클 | 4서클 |
|---|---|---|---|---|
| 불 | 플라미스 ✅ | 이그니스 ✅ · 칼로르 | 플라미스 로타 | |
| 물 · 얼음 | 아쿠엘 ✅ | 벨룸 · 겔루(얼음) | 운다 | |
| 바람 | 벤투스 ✅ | 라미나 · 살투스 | 벤투스 막시마 | |
| 땅 · 풀 | 라피스 · 아로 | 무루스 · 비멘(풀) | | |
| 신성 · 빛 | | 사나(신성) · 루키다(빛) | 푸르가(신성) · 풀멘(빛) | |
| 흑마법 · 그림자술 | | | 마쿨라 · 칼리고 · 라쿠에우스 | 하우리오 |

- 슬라이스 지역(마법탑 · 깊은 숲 · 폭풍 해안)의 서클 1~4 안에서 모두 얻을 수 있다. 계열마다 **공격 · 상호작용 · 방어나 생존 · 콤보 준비**가 한 장씩 들어가게 골랐다(예: 운다로 적시고 → 풀멘으로 감전, 겔루로 얼림).
- 노말은 슬라이스에 **스쿠툼**(Q 방어 자리, Q41)과 그 반격 **레토르타**를 더 넣는다. 수리 · 지우기 · 생물 보관은 그 시스템의 마일스톤(M4 · M5)을 따른다.

## 구현할 때

- 책을 실제로 넣을 때는 `Items.csv` 에 `Skillbook_<SpellId>` 행(Kind = Skillbook, `TeachesSpell` = SpellId)과 마법 정의 `DA_Spell_<SpellId>`(`Scripts/Magic/make_spells.py` 처럼 스크립트로)를 만든다. 튜토리얼 · 퀘스트의 `Skillbook:<SpellId>` 지급은 이 아이템을 가방에 넣는다. `Skillbooks.csv` 는 기획 목록이라 게임이 읽지 않는다(표 뽑기 `Scripts/Magic/skillbooks_md.py` 만 읽는다).
- 속성 태그는 그리모어 문양 · 연출이 쓰는 이름을 따랐다: 빛 = `Element.Light.Radiance`, 흑마법 = `Element.Dark.Hex`. `PactumSpells.csv` 의 자리 행은 `Element.Light` · `Element.Dark.Curse` 라 그 행을 만들 때 맞춘다.
- 이그니스는 지금 「큰 플라미스」(수치만 큰 Bolt)다. 목록의 「맞은 곳 둘레 1.5m 에 불이 옮는다」는 제안 — 넣으면 플라미스와 원리가 갈려 이름 규칙 3에도 맞는다.
- 새 방식(자신 · 아군 · 지점 · 몸 둘레 · 지역)은 `EGrimSpellDelivery`(`Source/Grimoire/Magic/GrimSpellDefinition.h` — 지금 값은 Bolt · Stream · Cone · Beam · Lob, Lob 은 Bolt 로 처리)에 값을 더하고 [마법 시스템](../systems/magic) 시전 흐름에 판정을 하나씩 붙인다. 슬라이스에 필요한 것은 자신 · 아군 · 지점 · 몸 둘레 넷이다.
