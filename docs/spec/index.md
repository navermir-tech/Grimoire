# 스펙 문서 — 개요

> 상태: **v0.2 초안** · 2026-11-04 · 원본 요구사항 16항목(R01~R16)을 영역별 문서로 정리했다. 바뀐 결정은 [결정 기록](./decisions)에 남긴다.

## 한 줄 요약

「그리모리」는 **완드로 마법을 쓰는 마법사가 되어, 마법 생물이 살아 숨 쉬는 오픈월드에서 살아남고 거점을 키우며, 1서클에서 10서클 신급 마법사에 이르러 사냥꾼 세력을 제압하는** 협동 생존 게임이다.

## 핵심 기둥 (Pillars)

설계가 갈릴 때 이 순서로 판단한다.

1. **마법이 곧 손이다** — 세계와의 모든 상호작용은 마법으로 한다. (R16, R01)
2. **서클이 곧 여정이다** — 1~10서클의 성장이 게임 전체의 뼈대다. (R05~R08, R10)
3. **생물은 자원이자 동료다** — 생태계 속 마법 생물을 사냥 · 길들이기 · 번식시켜 생존과 거점에 쓴다. (R02, R14, R15)
4. **살아남아야 마법사다** — 생존 스탯과 환경이 매 순간 선택을 만든다. (R03, R04)
5. **거점은 함께 키운다** — 하우징과 로컬 서버 협동. (R11, R13)

## 핵심 루프

- **분 단위**: 탐험 → 생물 · 사물을 마법으로 상호작용 → 자원 · 먹이 획득 → 생존 스탯 관리
- **시간 단위**: 거점으로 귀환 → 건축 · 농사 · 생산 · 생물 돌보기 → 스킬북 습득 · 서클 승급 준비 → 더 먼 기후 지역 · 던전
- **전체**: 마법탑(1서클) → 지역 확장 · 사냥꾼과 충돌 → 서클 승급 반복 → 10서클 신급 + 사냥꾼 제압 (R10)

## 문서 관리 방법

- 스펙이 바뀌면 해당 문서를 고치고 [결정 기록](./decisions)에 날짜 · 결정 · 까닭 한 줄을 더한다. 원문 표(R01~R16)는 고치지 않고, 바뀐 뜻은 각 문서에서 설명한다.
- **▢** 는 미결, **제안** 은 기본안(확정 전)이다. 확정되면 표시를 뗀다.
- 시스템(구현) 쪽은 [시스템 문서](../systems/)가 맡는다. 스펙은 "무엇을", 시스템은 "어떻게".
