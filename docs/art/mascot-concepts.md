## 디자인 원칙

생물 콘셉트의 「킥」 규칙([마법 생물 콘셉트](./creature-concepts))을 그대로 따르되, 마스코트라 **더 귀엽고 단순하게** 했다. 생물 콘셉트는 「포켓몬 · 팰월드 같은 마스코트풍」을 피하지만, 마스코트는 바로 그 자리를 맡는다.

| 원칙 | 뜻 |
|---|---|
| 실루엣 | 엄지 크기 아이콘 · 인형 · 스티커 · 로고로 줄여도 알아본다. 큰 모양 2~3개 · 주색 2~3개 · 잔무늬 없음 |
| 비율 · 표정 | 머리 : 몸 ≈ 1 : 1, 짧고 통통한 팔다리, 아주 큰 눈. 시안마다 표정을 돕는 부위(책장 귀 · 깃펜 아가미 · 더듬이 · 등불 · 비늘 · 눈자루)가 있다 |
| 마법 생물다움 | 몸 일부가 마법 물질(책장 · 잉크 펜촉 · 마법진 날개 · 등불 유리 · 마나 수정 · 탑)이고, 큰 그림은 마법을 쓰는 순간 |
| 구현 가능성 | 몸은 메시 · 재질로 만드는 또렷한 덩어리, 흩어지는 것(빛가루 · 불티 · 글자 가루)은 FX — FX 를 지워도 실루엣이 선다 |
| 화풍 | [아트 방향](../spec/art-direction)의 가장 귀여운 끝 — 3D 스타일라이즈드 캐릭터 렌더 마감 · 사실적 PBR 재질 · 회화적 빛. 2D 셀 애니 · 치비 · 플라스틱 장난감 광택은 피한다 |
| 독창성 | 피카츄 · 이브이 · 까부냥 · 램볼 · 커비 · 토토로 등과 실루엣 · 색 조합 · 귀 모양이 겹치지 않게 — 시안마다 「닮을 위험」을 적고 프롬프트에서 피했다 |

시트 읽는 법: 왼쪽 큰 그림 = 마법 쓰는 순간(3/4), 오른쪽 위 = 정면 · 옆, 가운데 = 표정 넷, 아래 왼쪽 = 키 1.8 m 사람 실루엣과 크기, 아래 오른쪽 = 색 변이. 그림을 누르면 크게 열린다.

## 1. 책장귀 {#pageling}

**처음 펼친 마법서에서 튀어나온, 귀가 책장인 작은 짐승.**

<div class="mascot-shot"><a :href="withBase('/art/mascot/pageling.jpg')" target="_blank"><img src="/art/mascot/pageling.jpg" alt="책장귀" loading="lazy"></a></div>

| | |
|---|---|
| 이름 후보 | 책깃이 · 페이지(Paige) · 리플(Riffle) |
| 오픈 베타 역할(제안) | **시작 동행 · 튜토리얼 안내** — 튜토리얼에서 첫 스킬북을 펼치면 책에서 튀어나와 따라다닌다. 새 마법을 배울 때마다 귀 책장에 그 마법의 룬이 새겨진다(스킬북 · 도감 안내 역). |
| 게임 연결 | 마법서(그리모어) — 게임 이름 그대로 |
| 크기 | 키 0.35 m(앉은키) |
| 주색 | <span class="sw"><i style="background:#7A2232"></i>버건디 가죽 <code>#7A2232</code></span> <span class="sw"><i style="background:#EFE2C2"></i>양피지 크림 <code>#EFE2C2</code></span> <span class="sw"><i style="background:#D9A93A"></i>금빛 잉크 <code>#D9A93A</code></span> |
| 마법 부위(메시 · 재질) | 귀가 책장이고 그 위 금빛 룬이 빛난다(재질 발광). 귀 책장을 펄럭여 잠깐 떠오른다 |
| 마법 쓰는 순간 | 귀 책장을 촤르륵 넘기며 공중에 떠오르고, 책장 한 장이 빛나는 룬 종이새로 접혀 앞으로 날아가는 순간 — 눈을 반짝이며 신난 얼굴 |
| FX | 날아가는 룬 종이새(종이 카드 메시 + 발광) · 금빛 잉크 글자 가루 · 넘어가는 책장 바람 |
| 표정 | 귀 책장이 표정을 돕는다 — 기쁨(책장 활짝) · 놀람(책장이 곤두서 펼쳐짐) · 겁(책장을 덮어 머리를 감쌈) · 졸림(책장이 축 처짐) |
| 색 변이 | 표지 색이 바뀐다 — 숲 가죽(짙은 초록 털 · 은빛 잉크), 밤하늘(남색 털 · 별빛 잉크), 돌연변이(흰 표지 털 · 검은 잉크 · 빨간 책갈피) |
| **닮을 위험** | 큰 귀의 둥근 짐승이라 이브이 · 피카츄 비율에 가깝다 → 귀는 뾰족한 털 귀가 아니라 **넓고 끝이 네모난 책장 부채**, 귀 끝 검정 금지, 노랑 · 갈색 몸 금지. 버건디 + 크림 + 금은 대표 마스코트들과 색이 겹치지 않는다. |

> **그림을 보고**: 의도대로 — 책장 부채 귀가 실루엣을 다 정한다(엄지 크기에서도 「책을 펼친 머리」). 겁 표정에서 책장을 덮어 머리를 감싸는 것이 가장 귀엽다. 흠: 털이 많은 얼굴이 그렘린 「기즈모」 쪽으로 살짝 간다 — 고르면 얼굴 털을 짧게 · 이마 크림 무늬를 더 또렷이.

## 2. 깃펜 도롱뇽 {#quillnewt}

**꼬리 끝 펜촉으로 허공에 룬을 쓰는 잉크빛 도롱뇽.**

<div class="mascot-shot"><a :href="withBase('/art/mascot/quillnewt.jpg')" target="_blank"><img src="/art/mascot/quillnewt.jpg" alt="깃펜 도롱뇽" loading="lazy"></a></div>

| | |
|---|---|
| 이름 후보 | 잉클리(Inkly) · 펜두 · 깃필이 |
| 오픈 베타 역할(제안) | **어디서나 만나는 흔한 종 · 마법탑 서기** — 1번 지역 개울 · 탑 서고 어디서나 보인다. 길들이면 거점에서 스킬북 · 두루마리를 베끼는 손재주 일꾼(스킬북 제작 안내). |
| 게임 연결 | 스킬북 · 룬 문자 · 마법탑 서고 |
| 크기 | 몸길이 0.4 m(꼬리 포함) |
| 주색 | <span class="sw"><i style="background:#1E2A55"></i>인디고 잉크 <code>#1E2A55</code></span> <span class="sw"><i style="background:#E0B040"></i>금빛 <code>#E0B040</code></span> <span class="sw"><i style="background:#F2E8D0"></i>크림 <code>#F2E8D0</code></span> |
| 마법 부위(메시 · 재질) | 꼬리 펜촉에서 빛나는 금빛 잉크가 나와 공중에 룬을 쓴다. 등의 금빛 잉크 점이 은은히 빛나며 몸 위를 천천히 옮겨 다닌다(재질 무늬) |
| 마법 쓰는 순간 | 뒷발로 서서 꼬리를 크게 휘둘러 공중에 빛나는 금빛 룬 원을 그리는 순간 — 깃펜 아가미가 활짝 펴지고 혀를 살짝 내민 집중한 얼굴 |
| FX | 공중에 남는 금빛 잉크 룬 자취 · 튀는 잉크 방울 |
| 표정 | 깃펜 아가미가 표정을 돕는다 — 기쁨(아가미 활짝) · 놀람(깃이 쭈뼛) · 시무룩(깃이 뒤로 접힘) · 집중(혀를 내밀고 눈을 가늘게) |
| 색 변이 | 잉크 색이 바뀐다 — 진홍 잉크(진홍 몸 · 금 펜촉), 먹빛(먹색 몸 · 은 펜촉), 돌연변이 투명 잉크(반투명 하늘색 몸 · 속에 금빛 점) |
| **닮을 위험** | 아홀로틀이라 우파루파 · 물짱이(포켓몬)와 겹칠 수 있다 → 몸은 남흑 잉크색(연하늘 · 분홍 금지), 아가미는 분홍 술이 아니라 **흰 깃펜**, 꼬리 끝 **펜촉**으로 실루엣을 갈라 놓는다. |

> **그림을 보고**: 의도대로 — 꼬리 펜촉 · 깃펜 아가미 · 등의 금빛 잉크 점이 다 읽히고, 젖은 잉크 광택이 3D 재질로 바로 옮겨진다. 표정 폭이 가장 넓다(혀 내민 집중 얼굴). 흠: 크기 비교의 작은 개체가 0.4 m 보다 작게 보인다.

## 3. 서클 나방 {#circlemoth}

**날개에 마법진(서클)이 새겨진 솜털 나방 — 서클이 오를수록 고리가 는다.**

<div class="mascot-shot"><a :href="withBase('/art/mascot/circlemoth.jpg')" target="_blank"><img src="/art/mascot/circlemoth.jpg" alt="서클 나방" loading="lazy"></a></div>

| | |
|---|---|
| 이름 후보 | 서클리(Circly) · 루미(Lumi) · 링모 |
| 오픈 베타 역할(제안) | **서클 승급의 상징 동행** — 플레이어가 서클을 올릴 때 날개 마법진의 고리 수가 함께 는다(성장 단계 1 → 3). 마법탑 로고 · 서클 UI 아이콘으로 바로 쓴다. |
| 게임 연결 | 서클 마법(1~10서클) · 마법진 |
| 크기 | 키 0.3 m(날개 폭 0.45 m) |
| 주색 | <span class="sw"><i style="background:#F4EFE6"></i>솜털 크림 <code>#F4EFE6</code></span> <span class="sw"><i style="background:#B8A6E0"></i>연보라 <code>#B8A6E0</code></span> <span class="sw"><i style="background:#5FE0D0"></i>마나 청록 빛 <code>#5FE0D0</code></span> |
| 마법 부위(메시 · 재질) | 날개의 마법진 무늬가 발광 재질로 빛나며 천천히 돈다. 고리 수 = 서클 단계(이 그림은 고리 둘) |
| 마법 쓰는 순간 | 날개를 활짝 펴 날갯짓하며 떠오르자 날개 마법진이 바닥에 그대로 비쳐 크고 둥근 빛 마법진이 펼쳐지는 순간 — 두 눈을 감고 행복하게 집중한 얼굴 |
| FX | 바닥에 펼쳐지는 빛 마법진(데칼) · 날개 비늘 빛가루 |
| 표정 | 더듬이가 표정을 돕는다 — 기쁨(더듬이 쫑긋) · 놀람(더듬이 곤두섬, 날개 펼침) · 졸림(더듬이 축 · 날개로 몸을 감쌈) · 집중(더듬이를 앞으로 모음) |
| 색 변이 | 날개 색이 속성 색 — 불(주황 날개 · 금빛 마법진), 물(파랑 날개 · 흰 마법진), 돌연변이(검보라 날개 · 금빛 마법진) |
| **닮을 위험** | 둥근 솜털 몸은 커비 비율, 솜털 나방은 분홍 · 노랑 「장미단풍나방」 밈 · 포켓몬 나방류(도나리 · 에보이드 등)와 겹칠 수 있다 → 분홍 · 노랑 조합 금지, 날개 무늬는 눈알 무늬가 아니라 **동심원 마법진**, 실루엣은 「더듬이 둘 + 날개 넷」. |

> **그림을 보고**: 의도대로 — 「더듬이 둘 + 날개 넷 + 솜털 공」 실루엣이 여섯 중 가장 아이콘답고, 바닥 마법진 데칼이 서클 마법을 그대로 보여 준다. 흠: 날개가 나비 날개에 가깝다(나방다운 넓은 앞날개로 다듬을 수 있음). 반투명 날개는 양면 메시 + 마스크 재질.
