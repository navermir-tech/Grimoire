# 마스코트 후보

> 상태: **v2 후보 8개 — 검토용** · 2026-11-20 · GPT 이미지(Codex CLI). 사용자 요청(2026-11-19) 「팰월드 까부냥, 포켓몬 피카츄처럼 게임 얼굴이 될 오리지널 마법 생물 — **오픈 베타에 꼭 넣는다**」.
>
> v1 시안 6개(아래 「옛 판(반려)」)는 사용자가 「너무 틀에 박힌 느낌」으로 반려했다 — 여섯이 모두 「귀여운 실제 동물 + 붙인 게임 소품 + 인형 비율」 한 공식이었다. v2 는 **고리(행동 · 성격 · 플레이어와의 관계)부터** 33개를 글로 쓰고 기준으로 쳐내 8개를 그렸다. 사용자가 좋아한 카벙클 · 켈피 · 맨드레이크처럼 귀여움을 인형 비율이 아니라 마법 생물다움과 행동에서 끌어낸다.
>

## 기준

그리기 전에 글로 통과시켰다(2026-11-20 메인 세션 정리).

| # | 기준 |
|---|---|
| 1 | 「실제 동물 + 붙인 마법 소품」 금지 — 마법이 꾸밈이 아니라 몸의 구조이거나 존재 이유 |
| 2 | **한 줄 고리** — 플레이어가 「걔 ○○한다?」 하고 남에게 말할 행동 · 성격 · 플레이어와의 관계 |
| 3 | **대비 하나** — 귀여운데 이상하다 · 작은데 위험하다 · 아름다운데 묘하다(공포 아님) · 하찮은 것이 마법적이다 |
| 4 | 실루엣으로 알아보고, 피카츄 · 이브이 · 까부냥 · 램볼 · 커비 · 토토로 · 파이널판타지 카벙클 · 모그리 등과 겹치지 않는다 |
| 5 | 그리모리 정체성과 닿는다 — 마법서 · 서클 · 마나 · 파크툼 계약 · 마법탑 · 생존 |
| 6 | 구현 가능성(몸은 메시 · 재질, 흩어지는 것은 FX)과 [아트 방향](../spec/art-direction)(회화적 3D 스타일라이즈드) |

그림은 시트가 아니라 **그 생물다운 순간 한 장**이다. 사람은 손 · 발 · 소매만 보인다(크기 비교). 그린 뒤 「캡처해서 남에게 보여 주고 싶은가 · 카벙클 · 켈피 옆에서 지지 않는가 · 또 동물 + 소품이 아닌가」로 스스로 평가해, 넷(불발이 · 갉작이 · 도장이 · 안 깬 알)은 첫 판을 버리고 다시 그렸다.

## 1. 불발이 {#misfire}

**「걔, 내가 튜토리얼에서 처음 쏜 주문이야. 빗나가서 덤불에 처박혔는데 다음 날 걸어 나왔어.」 — 첫 주문의 속성 색이 플레이어마다 다르다.**

<div class="mascot-shot"><a :href="withBase('/art/mascot/misfire.jpg')" target="_blank"><img src="/art/mascot/misfire.jpg" alt="불발이" loading="lazy"></a></div>

| | |
|---|---|
| 이름 후보 | 불발이 · 피식이(Fizzle) · 빗나리 |
| 대비 | 하찮은 것(실패한 주문)이 마법적 · 귀여운데 엉성하다 |
| 그리모리와 닿는 곳 | 튜토리얼 첫 기본 공격 · 마나 — 내 실수가 낳은 동행 |
| 크기 | 몸길이 0.35 m |
| 생김새(메시 · 재질) | 날아가던 마법 탄환이 그대로 굳어 생물이 된 몸. 앞쪽은 주먹만 한 둥근 탄두 — 속에서 푸른 마나 불꽃이 소용돌이치는 맑은 덩어리. 그 뒤로 **혜성 꼬리처럼 넓게 퍼졌다가 날렵하게 모이는 꼬리 자취**가 조각처럼 굳어 있다 — 바람에 날리던 모양 그대로 휘날리는 리본 같은 덩어리 셋이 위로 휘어 올라가고, 끝 하나가 덤불에 처박힌 흔적처럼 구겨져 꺾였다(병목 · 관 · 원통 모양이 아니다). 탄두 아래에서 가는 잔뿌리 같은 다리 셋이 자라나 비틀비틀 선다(흙과 풀 부스러기). 탄두 앞쪽에 크고 또렷한 빛 눈 둘 — 위쪽이 눈꺼풀처럼 깎인 둥근 빛이라 놀람 · 민망함 같은 표정이 읽힌다. 입 · 털 · 동물 얼굴 없음. 유리병 · 플라스크처럼 보이면 실패 |
| FX | 꽁무니의 피식 불티 · 가는 연기 한 줄 |
| **닮을 위험** | 도깨비불 · 윌오위스프 · 혜성 캐릭터, 커비의 별, 캘시퍼(불꽃 얼굴)와 겹칠 수 있다 → 몸은 불이 아니라 굳은 유리 같은 마법, 탄두 + 굳은 꼬리 자취 + 잔뿌리 다리 셋의 실루엣. |
| **그림 평가** | 첫 판은 「다리 달린 유리 플라스크」로 읽혀 버렸다(쳐낸 물약병과 겹침). 둘째 판 — 혜성 꼬리 리본 셋 · 코를 박고 버둥거리는 잔뿌리 다리 · 민망하게 찡그린 눈으로 「빗나간 주문」이 웃기게 읽힌다. 흠: 꼬리 리본이 불꽃 · 유령 꼬리로도 보인다 — 다듬을 때 끝을 더 단단한 조각으로. |

## 2. 끄적이 {#doodle}

**「걔 원래 내 스킬북 여백에 누가 그려 놓은 낙서였어. 세상은 다 진짜인데 걔만 펜 선이야.」 — 발끝으로 허공에 그린 것은 잠깐 진짜가 된다.**

| | |
|---|---|
| 이름 후보 | 끄적이 · 여백이 · 스크리블(Scribble) |
| 대비 | 하찮은 것(낙서)이 마법적 · 혼자만 다른 그림체라 귀여운데 이상하다 |
| 그리모리와 닿는 곳 | 마법서 · 스킬북 |
| 크기 | 키 0.3 m |
| 생김새(메시 · 재질) | 견습생이 책 여백에 대충 그린 낙서 생물이 그대로 입체가 된 몸 — 둥글고 삐뚤빼뚤한 몸, 한쪽 귀가 더 크고 접혔다, 막대기 같은 다리 넷(그중 하나는 한 번 줄 그어 지우고 다시 그린 자국), 점 두 개 눈과 꼬불한 한 줄 입, 끝이 동그랗게 말린 꼬리 한 줄. 몸 전체가 오래된 양피지 색 바탕에 갈색 잉크 펜 선(굵기가 들쭉날쭉한 외곽선 · 빗금 음영 · 잉크 번짐)으로 「그려져」 있다 — 둘레의 사실적인 풀밭 · 돌 속에서 혼자 손그림 펜화 재질. 입체 몸이지만 표면은 펜화 |
| FX | 그려지는 선 끝의 잉크 번짐 · 지우개 가루처럼 흩어지는 선 조각 |
| **닮을 위험** | 페이퍼 마리오 · 오카미 붓 · 「드로운 투 라이프」와 겹칠 수 있다 → 종이 인형이 아니라 입체 몸에 펜화 재질, 낙서 그림체(점 눈 · 삐뚤한 선 · 지운 자국). |
| **그림 평가** | 한 번에 통과 — 사실적인 개울 · 돌 사이에서 혼자 펜화라 「그림체가 다른 생물」이 바로 읽히고, 지운 다리 자국(X) · 그리다 만 다리에서 떨어지는 잉크까지 고리가 그림에 다 있다. 흠: 몸이 거친 양피지 질감이라 펜 선이 덜 보이는 면이 있다. 구현은 외곽선 셰이더 + 빗금 재질. |

## 3. 갉작이 {#scrollmite}

**「걔가 내 스킬북을 갉아먹으면 그 마법을 쓸 줄 알게 돼. 아끼는 책은 숨겨야 해.」**

<div class="mascot-shot"><a :href="withBase('/art/mascot/scrollmite.jpg')" target="_blank"><img src="/art/mascot/scrollmite.jpg" alt="갉작이" loading="lazy"></a></div>

| | |
|---|---|
| 이름 후보 | 갉작이 · 두루미(두루마리 벌레) · 북마이트(Bookmite) |
| 대비 | 귀여운데 말썽(도둑) · 하찮은 것이 마법적 |
| 그리모리와 닿는 곳 | 스킬북 · 마법 배우기 |
| 크기 | 몸길이 0.3 m(펼치면 0.5 m) |
| 생김새(메시 · 재질) | 살아 있는 두루마리 — 몸은 둘둘 말린 누런 양피지 원통이고, 자벌레처럼 말렸다 펴지며 기어간다. 앞쪽 끝이 머리: 양피지가 두건처럼 접혀 얼굴을 감싸고, 그 그늘 속 얼굴은 **종이에 떨어진 잉크 방울 두 개가 눈**(흰자 · 홍채 없는 반들반들한 까만 점, 빛 반사 하나)이고 코 · 볼 · 사람 피부 없음 — 얼굴 바탕도 양피지 그대로, 입은 종이를 갉아 먹은 반달 모양 작은 구멍 하나. 사람 얼굴 · 반죽 인형 얼굴이면 실패. 몸 가장자리는 갉아 먹은 듯 들쭉날쭉하고 군데군데 잉크 얼룩. 아래에 붉은 봉랍 방울 같은 작고 둥근 발 몇 쌍. 펼쳐지는 안쪽 면에 마지막으로 먹은 마법의 룬이 빛난다. 애벌레 마디 · 곤충 다리 없음 |
| FX | 뱉은 작은 불덩이 · 날리는 종잇조각 · 룬 빛 |
| **닮을 위험** | 캐터피 · 책벌레 · 해리포터 「괴물들의 괴물 책」과 겹칠 수 있다 → 이빨 달린 책이 아니라 두루마리 몸, 애벌레 마디 · 다리 없음. |
| **그림 평가** | 첫 판은 흰자 있는 사람 눈 · 코의 반죽 인형 얼굴이라 섬뜩해서 버렸다. 둘째 판 — 잉크 방울 눈 · 갉아 먹는 입 · 뱉는 불덩이 · 갉아 먹힌 책으로 말썽꾸러기 귀여움이 산다. 흠: 발이 봉랍 방울이라 도장이와 재료가 겹친다. |

| 생김새(메시 · 재질) | 머리 위에 떠 있는 작은 흙섬 — 위는 둥근 흙 바닥, 밑면에서 풀 · 잔뿌리 · 거꾸로 핀 작은 들꽃이 아래로 늘어진다. 생물은 그 흙섬 밑면에 발을 딛고 거꾸로 서 있다(발이 위, 머리가 아래). 몸은 특정 동물이 아닌 작은 존재 — 가늘고 긴 팔다리, 물방울처럼 아래로 둥근 몸, 동그란 얼굴에 크고 졸린 눈, 길고 가는 꼬리. 부드러운 회청색 털인데 털과 꼬리가 중력 반대로 「위로」(자기 땅 쪽으로) 흘러내린다. 흙섬 가장자리에 작은 돌 몇 개가 함께 떠 있다 |
| FX | 위로 떨어지는 빗방울 · 흙섬에서 흩날리는 꽃잎 |
| **닮을 위험** | 나무늘보 · 박쥐 · 여우원숭이와 겹칠 수 있다 → 머리 위 흙섬과 위로 흐르는 털로 실루엣을 바꾸고, 어떤 동물 얼굴도 아니게. |
| **그림 평가** | 한 번에 통과 — 여덟 중 가장 「아름다운데 묘한」 그림으로, 카벙클 옆에 둬도 지지 않는다. 흠: 빗방울이 위가 아니라 아래로 떨어지고(고리의 한 조각이 빠짐), 털도 위로 흐르기보다 아래로 늘어졌다 — 다시 그릴 때 강조. |

| **그림 평가** | 한 번에 통과 — 장화 앞의 허세와 바닥의 무지갯빛 장미 무늬가 한 장에 다 읽힌다. 「캡처해서 보여 주고 싶은」 그림으로는 여덟 중 첫째. 흠: 몸이 그레이하운드 · 캥거루 쪽으로 기울고, 비장한 표정이 덜 보인다. |

## 7. 도장이 {#waxseal}

**「걔가 내 계약서에 도장을 찍어 줘. 생물이랑 계약할 때마다 그 생물 문양이 걔 몸에 하나씩 찍혀 — 걔 몸이 내 도감이야.」**

<div class="mascot-shot"><a :href="withBase('/art/mascot/waxseal.jpg')" target="_blank"><img src="/art/mascot/waxseal.jpg" alt="도장이" loading="lazy"></a></div>

| | |
|---|---|
| 이름 후보 | 도장이 · 실링(Sealing) · 봉랍이 |
| 대비 | 작은 관료 — 귀여운데 진지하다 |
| 그리모리와 닿는 곳 | 파크툼 계약 · 도감 |
| 크기 | 키 0.25 m |
| 생김새(메시 · 재질) | 편지 봉투에 찍는 **봉랍 인장 하나가 그대로 생물이 된 몸** — 손바닥만 한 지름 20 cm, 두께는 손가락 두 마디(4 cm)뿐인 납작한 원반을 동전처럼 옆으로 세웠다. 공 · 구 · 통통한 몸통이 아니다. 가장자리는 밀랍이 눌려 퍼진 물결 모양 테두리. 앞면 한가운데 눌러 찍힌 오목한 문장(작은 탑 문양)이 얼굴 — 그 안에 반짝이는 작은 눈 둘. 원반 아래로 흘러 굳은 밀랍 방울 넷이 짧고 동글동글한 다리(발가락 · 근육 없음), 뒤쪽에 가는 리본 끈 한 가닥이 꼬리처럼. 원반 테두리 둘레에 작은 인장 자국들(갈라진 뿔 · 물결 갈기 · 잎). 재질은 반들반들 굳은 짙은 진홍 밀랍 — 매끈하고 광택 있는 사탕 같은 표면, 금빛 운모 알갱이가 살짝(날고기 · 근육 · 끈적이는 살 질감 금지) |

| **닮을 위험** | 슬라임(드래곤 퀘스트) · 불켜미(밀랍 양초)와 겹칠 수 있다 → 물방울 모양이 아니라 납작한 원반 인장, 불꽃 · 심지 없음. |
| **그림 평가** | 세 번 그렸다 — 첫 · 둘째 판은 공 모양 날고기 덩어리로 나와 버렸다. 셋째 판은 납작한 봉랍 원반이 뿌듯하게 도장을 찍지만, 다리가 소시지 같고 토끼보다 크다. **여덟 중 가장 약하다** — 고리(몸이 도감)는 좋으니 고리만 다른 후보에 붙이는 길도 있다. |

## 쳐낸 후보 — 25개

고리를 먼저 쓴 후보 33개 가운데 기준으로 쳐낸 것. 고리가 좋은 것은 남은 후보에 녹였다.

| 후보 | 고리 | 쳐낸 까닭 |
|---|---|---|
| 촛농 문지기 | 녹아내리는 양초 몸, 심지 불꽃이 기분 | 불켜미(포켓몬) · 캘시퍼와 겹친다 |
| 자칭 용 불씨 | 자기가 용인 줄 아는 작은 불씨 — 재채기로 모닥불을 피우고 뽐낸다 | 무슈 · 스파이로 · 캘시퍼, 결국 「도마뱀 + 불」 |
| 낮잠 가고일 | 낮엔 탑 처마의 돌 조각, 밤엔 살아서 거점을 지킨다 | 가고일은 흔하고 레퍼런스(호그와트 레거시)에 이미 있다 |
| 살아 있는 열쇠 | 아무 문이나 열어 주는 열쇠 생물 | 클레피(포켓몬) |
| 미믹 지갑 | 재료를 훔쳐 가는 가방 — 열면 남의 것도 들어 있다 | 미믹 · 디스크월드 「짐 상자」 트로프 |
| 마나 방울 | 쓰고 남은 마나가 뭉친 젤리 | 드래곤 퀘스트 슬라임, 모양이 정해지지 않는다 |
| 먼지 토끼 | 탑 구석 먼지가 마나를 쬐어 생긴 털뭉치 — 청소하면 운다 | 토토로 검댕이 |
| 구르는 마법진 | 바퀴처럼 굴러다니는 서클 고리 — 밟으면 마법이 터진다 | 동탁군(포켓몬), 표정 · 귀여움이 약하다 |
| 메아리 종 | 내가 쓴 마법을 한 박자 늦게, 조금 틀리게 따라 쓴다 | 고리는 좋지만 몸(종)이 동탁군 · 랑딸랑과 겹친다 — 고리는 「불발이」 · 「갉작이」에 녹였다 |
| 마나 청소부 | 싸움이 끝나면 나타나 바닥에 흘린 마나를 핥는다 | 개미핥기 = 동물 공식, 「불발이」와 고리가 겹친다 |
| 별자리 고양이 | 밤에만 별 점과 선으로 이어진 몸이 보인다 | 몸이 흩어지는 FX 라 메시로 못 서고, 「우주 고양이」는 흔하다 |
| 종이학 전령 | 편지를 접어 날리면 학이 되어 배달한다 | 흔한 종이접기 트로프, 성격이 없다 |
| 물약병 은둔자 | 물약병 속에서 안 나오고 병째 걸어 다닌다 | v1 소라게와 같은 「동물 + 집」 공식 |
| 줄 없는 꼭두각시 | 줄이 없는데 하늘에서 당기는 것처럼 움직인다 | 공포 쪽으로 기운다 |
| 빈 망토 | 안에 아무도 없는 견습생 망토 | 가오나시 · 미미키 · 디멘터 |
| 모자 속 생물 | 마법사 모자 속에 살며 가끔 내다본다 | 해리포터 「마법의 모자」, 동물 + 소품 |
| 작은 비구름 | 따라다니며 밭에 비를 뿌린다 | 라키 · 파비코, 몸이 FX |
| 하늘고래 새끼 | 작은데 언젠가 섬만 해진다 | 하늘고래 트로프, 동물 그대로 |
| 변신 실패 찻주전자 고양이 | 변신 마법 실패작 — 반은 찻주전자 | 「동물 + 소품」 공식을 글자 그대로 한 것 |
| 꿈꾸는 버섯 | 버섯 갓 아래서 남의 꿈을 키운다 | 키노피오 · 뽀록나, 버섯 생물은 흔하다 |
| 돌무더기 길잡이 | 돌탑이 걸어 다니며 길을 표시한다 — 가끔 엉뚱한 데로 | 골렘 · 꼬마돌, 귀여움이 약하다 |
| 거울 따라쟁이 | 내 옷 · 모자를 따라 입는다 | 메타몽, 제 생김새가 안 잡힌다 |
| 열쇠구멍 | 몸이 허공에 난 구멍 — 들여다보면 다른 곳이 보인다 | 귀여움이 약하고 렌더 비용이 크다 |
| 잠 양 | 잠 못 들 때 세던 양이 진짜 생긴다 | 결국 양 = 동물 공식 |
| 새싹 머리 | 머리에서 마나 새싹이 자란다 | 피크민 · 이상해씨 |

## 만든 과정

- 후보 · 프롬프트의 정본 `art/mascot/make_prompts.py`(`CANDIDATES` · `REJECTED` · 공통 `RULES` · `STYLE`), 프롬프트 `art/mascot/prompts/`, 이 페이지 · JPG · 비교 그림은 `art/mascot/publish.py`. 원본 PNG `art/mascot/raw/`(버린 첫 판은 `raw/rejected/`)는 git 에 올리지 않는다.
- 그리기는 생물 콘셉트와 같은 `art/tools/run_codex_job.sh` — 그림 하나에 codex 세션 하나, 자기 세션 폴더의 그림인지 비교한다. 같은 파이프라인을 쓰는 다른 세션과 섞이지 않게 한 번에 2장까지만 돌렸다.
