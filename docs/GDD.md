## 2. 핵심 컨셉

- 제목의 **그리모어(Grimoire)** 는 마법서다. 후보 훅: *플레이어의 그리모어가 곧 성장 · 인벤토리 · 조합대다* — 세계를 탐험하며 주문을 발견해 책에 기록하고, 책 안에서 주문을 엮어 새 마법을 만든다.
- ▢ 이 게임만의 한 가지(다른 마법 게임과 다른 점)
- ▢ 플레이어 판타지(플레이어가 느껴야 할 기분)

## 5. 마법 시스템 (이 게임의 심장)

- ▢ 주문의 구성 요소 — 예: 원소(불 · 물 · 바람 · 땅 …) × 형태(투사체 · 범위 · 지속 · 소환 …) × 수식(위력 · 범위 · 속도 …)
- ▢ 획득 방식 — 발견 / 해독 / 전수 / 조합
- ▢ 자원 — 마나 · 쿨다운 · 잉크 · 페이지 수 …
- ▢ 그리모어 UI — 책을 펼치는 화면, 페이지 = 주문 슬롯?
- ▢ 위험 요소 — 시전 실패 · 폭주 · 금서 같은 긴장이 있는가
- 기술 메모: 주문 · 버프 · 자원 · 쿨다운은 **Gameplay Ability System(GAS)** 로 구현하는 쪽을 검토한다(`Source/Grimoire/Grimoire.Build.cs` 주석 참고).

## 11. 기술

- 엔진 **Unreal Engine 5.8**, C++ 모듈 `Grimoire` + 블루프린트. 입력은 Enhanced Input.
- 렌더링: Lumen(동적 GI · 반사) · Virtual Shadow Maps · DX12 SM6 (`Config/DefaultEngine.ini`).
- 검토 중: GAS(마법), StateTree(적 AI), Common UI(패드 · 마우스 공용 UI), World Partition(열린 세계일 때).
