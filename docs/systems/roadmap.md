1. 플러그인 활성화(GameplayAbilities · StateTree · Niagara), `AGrimoireGameMode` → `AGrimGameMode` 로 확장, PlayerState · ASC.
2. 3인칭 캐릭터(엔진 TP_ThirdPerson 템플릿 콘텐츠를 `Content/ThirdPerson/` 로 가져와 임시 사용) + Enhanced Input.
3. `UGrimSpellDefinition` · `UGrimSpellAbility` · `AGrimWand` · 투사체.
4. `UGrimElementalStateComponent` + `DT_ElementalReactions` + `BP_Candle`.
5. 시간 서브시스템 + 하늘. 생존 어트리뷰트 4개.
6. PIE 2 클라이언트로 상호작용 복제 확인 → 문서 갱신 → M1 완료.

## 기술 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| **범위** — 생존 + 생물 + 건축 + 멀티 + 상호작용은 각각 게임 하나 분량 | 완성 못 함 | 마일스톤별 완료 기준 엄수. M7 전까지 "종 · 지역 · 마법 수"를 늘리지 않음 |
| 멀티 복제 비용 — 사물 수천 개의 속성 상태 | 대역폭 · CPU | Dormancy · FastArray · 상태 있을 때만 활성. 초기부터 PIE 2인으로 측정 |
| GAS 학습 곡선 | 초기 속도 | Lyra 샘플 · 공식 문서 참고. M1 에서 패턴 확정 후 반복 |
| 인스턴스 던전의 좌표 슬롯 방식 | 예상 못 한 엔진 제약 | M6 전 프로토타입으로 검증. 실패 시 서버 트래블 던전(멀티 제한)으로 후퇴 |
| 전용 서버 = 소스 빌드 엔진 필요 | 빌드 환경 | 리슨 서버로 충분히 가고 M6 이후 판단 |
| 콘텐츠 제작(생물 모델 · 애니메이션) | 시간 | 에셋 스토어(Fab) · 색상 변이로 종 수 절약. 돌연변이는 색만 |
| 한글 · 공백 · OneDrive 경로 — C++ 빌드 실패(cl.exe 응답 파일 CP949 문제) · 동기화 폭주 | M1 착수 불가 | **해결(2026-11-05)**: 프로젝트를 `C:\Dev\Grimoire` 로 이동해 빌드 확인. 다른 PC 에서도 영문 경로에 받는다 — [시작하기](../dev/setup) |
